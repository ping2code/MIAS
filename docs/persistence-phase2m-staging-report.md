### Finding (reported, not repaired): disclosure time promoted after Redis expiry

After alias/policy expiry, a durable hit reused the existing event, but the collector's cached result
carried the companion's later disclosure because Redis no longer remembered the earlier one. The
Phase 2D promotion rule treats a strictly later disclosure as newer material, so the current version
now shows the later time; re-observing the earlier time is a duplicate of the older version and
cannot re-promote. Identity, history, audit, Redis and alerting are unaffected. Versions of that event:

- `2026-09-22 12:00:00+00:00` current=False
- `2026-09-22 13:00:00+00:00` current=True
